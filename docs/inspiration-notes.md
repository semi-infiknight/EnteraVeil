# Synthesis — 8 concrete moves

Each move below names the inspo source, the exact computed-style
evidence I pulled from the JSON above, and what it would mean for
EnteraVeil. Polish prompts can pick any of these in isolation; none
of them are applied yet.

## 1. **Bungee** as the third type tier (comicsense + xenpachi)

**Evidence:** comicsense renders its category h1s ("TEE",
"SWEATSHIRT", "HOODIE") in `Bungee, sans-serif` at `28.8px`,
weight 400, `text-transform: uppercase`, line-height `56px`.
Their h3 category cards ("Tees", "COSPLAY jersey", "tapestry") use
`Bungee 25px / 37.5px`. Xenpachi *also* loads Bungee in its
`@font-face` set (`Bungee weight=400`), confirming it's the
shared "anime streetwear poster" face on both sites.

**What EV has today:** display tier is Bricolage Grotesque + Space
Grotesk + JetBrains Mono. No poster-style face.

**Move:** add Bungee as a fourth font slot (`--font-poster`) and use
it ONLY for callouts that should read like a sticker print — "DROP
001", "LIVE NOW" pill, category section labels, the 404 numeral
"404". Pair with the existing eyebrow rule. Bricolage stays the
workhorse display; Bungee is a graphic flourish, not a replacement.

## 2. Background-scale category labels behind product blocks (comicsense)

**Evidence:** comicsense h1 colour for category labels is
`rgba(0, 0, 0, 0.48)` — half-opacity black, sitting behind imagery.
Combined with `Bungee 28.8px` uppercase, they read as decorative
chapter markers rather than headings.

**What EV has today:** SectionDivider gives a numbered chapter
("01 — Collections") but the title floats above content as ev-
display-soft, fully opaque, no decorative sibling.

**Move:** add a `.ev-chapter-mark` utility — a translucent Bungee
label (40-72px, opacity 0.18 on dark, mix-blend-overlay) that sits
behind shop / category / lookbook section heroes. E.g., the shop
filter strip gets a giant translucent "SHOP" word behind it; the
lookbook page gets a giant "LOOKBOOK" word behind the grid.

## 3. Promo-content marquees, not brand-fluff marquees (comicsense)

**Evidence:** comicsense ships **four** marquees with copy like
`'Shop for 1500 to 1999 and get a Woven keychain. Use code
"KEYCHAN"'`, `'Shop for 4000 or above and get a Free DIY Katana.
Use code "DIYKATANA"'`. They double as a tiered-offer ladder.
Xenpachi has 2 marquees: one warning ("delays due to WAR"), one
offer ("Buy 2 & get 1 Free on 'No Restock Club'!").

**What EV has today:** two marquees, both brand fluff —
`'★ Drop 001 ★ EnteraVeil beyond the veil anime streetwear made
in Bangalore numbered runs small batch'` and `'Hand-printed
Numbered Small batch Anime DNA Shipped from BLR Made for the
void'`.

**Move:** swap one of the two marquees for a **functional** strip:
free-shipping threshold ("FREE SHIPPING OVER ₹1,500 · USE CODE
DROP001 FOR 15% OFF · COD ACROSS INDIA · 7-DAY RETURNS"). Keep
the other as the brand chant. Functional reads as a real ecom
site; brand reads as the editorial flourish.

## 4. Sharp-cornered CTAs alongside the rounded ones (xenpachi)

**Evidence:** xenpachi's primary buttons measure `borderRadius:
3px` / `5px`, padding `5px 20px` or `0px 15px`, weight 500. None
are pill-shaped. Comicsense's are also `borderRadius: 0px` mostly
(menu items) or `2px`.

**What EV has today:** every Button variant is `rounded-3xl`
(fully pill-shaped). Reads slick-app, not street-print.

**Move:** introduce a `Button variant="poster"` — same sizing as
filled, but `rounded-[4px]` + slightly heavier weight + Bungee
or wide-tracked sans for the label. Use it on the hero primary
CTA, "Shop the drop" buttons in section headings, the cart
checkout button. The default pill stays everywhere else (forms,
toasts, micro-actions) so the system has a tier.

## 5. Tight-to-overlapping line-height on hero display (xenpachi)

**Evidence:** xenpachi h2 = `fontSize 48px / lineHeight 16px`,
h3 = `fontSize 40px / lineHeight 16px`. Lines literally collide.
This is graphic design's "set type so tight the descenders kiss"
move — looks like a printed poster, not a website.

**What EV has today:** `.ev-display` is `line-height: 0.86` — tight
but not extreme. Hero "Beyond / the veil." sits comfortably with
breathing room between the two lines.

**Move:** add `.ev-display-collapsed` at `line-height: 0.74` and
optionally apply to hero h1 alone. The "Beyond" / "the veil."
break would close up so the descender on "Beyond" almost touches
the cap-height on "the".

## 6. Second brand accent on hover / state pills (comicsense)

**Evidence:** comicsense has TWO accent colours — `rgb(94, 63,
222)` purple (456 text uses, 456 border uses) and `rgb(255, 36,
170)` magenta-pink (375 / 364 uses). Plus a `rgb(0, 128, 64)`
green that appears only on in-stock indicators (69 uses).

**What EV has today:** gold `#FFB627` on near-black, that's the
entire palette. Every accent — selection ring, focus ring, link
underline, badge text — is the same gold. Reads disciplined but
flat.

**Move:** introduce a **second** accent — electric magenta
`#E91E63` or violet `#7C3AED` — used ONLY for two slots:
(a) state pills on the order card ("Shipped" → magenta dot,
"Delivered" → green dot, prior gold reserved for "Placed");
(b) the wishlist / save-for-later icon when active. Everything
else stays gold. Two accents = a brand, three+ = chaos; two is
the sweet spot the inspo sites land on.

## 7. Wishlist heart per product card (comicsense)

**Evidence:** every comicsense product card has an absolute-
positioned wishlist heart `<button class="ct-wishlist-button-
archive">` with a hand-drawn SVG that toggles fill state. It's
top-right, always-visible (not hover-only).

**What EV has today:** product tile shows a hover-only quick-add
bag icon bottom-right, and three small palette dots bottom-left.
No save / wishlist concept.

**Move:** add a localStorage-backed "save" heart top-right of
every ProductTile — outline by default, filled in the new
magenta on click. No backend, just `localStorage['ev-saved']`
as a Set of product handles. The icon reads as anime-merch
DNA without any new server work.

## 8. Stacked offer ladder ABOVE the marquee (comicsense)

**Evidence:** comicsense layers their offers — the first marquee
is the always-on rules ("FREE SHIPPING OVER ₹X"), and above
that they have a static banner that hosts the current campaign
("Use code KEYCHAN", "Use code DIYKATANA"). Two-tier
communication, marquee = continuous, banner = current campaign.

**What EV has today:** one marquee at the very top, nothing above
it.

**Move:** above the marquee, add a thin static line —
`bg-ev-deep`, ev-mono 10px, gold dot pulse — with a single
rotating offer ("SS26 DROP IS LIVE · Use code DROP001 at
checkout"). Dismissible (localStorage). Marquee stays below for
the always-on rules. Pattern matches both inspo sites' tiered
comms style.

## Inspo divergences (i.e. what NOT to copy)

- **Light backgrounds.** Both sites use `rgb(242, 245, 247)` light
  greyish-blue as body bg. EV is committed to dark mode default and
  it's a brand choice worth keeping. Don't flip the surface.
- **Multi-colour h1 hover-state flashes.** comicsense flips between
  purple, pink, green frequently. EV with gold-only is calmer and
  reads more premium — don't dilute with three+ accents.
- **Playfair Display.** xenpachi leans serif, which on dark surfaces
  reads too academic for the streetwear DNA. Stick with the
  Bricolage Grotesque + Bungee combo.
- **Square product cards with centered text.** comicsense cards are
  white, centered, text-only-below — Walmart-y. EV's left-aligned
  editorial tile (Pass D) is better; don't regress.
